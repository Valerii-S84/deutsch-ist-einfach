# Адміністративна статистика — 14 вересня 2026

Розгорнуто runtime commit `824c9146801aa8b894b1140a33b5a82cffdb3663`.
Вхід: https://deutschmit.de/admin/products.
Shorts Blocker Kids: https://deutschmit.de/admin/shorts-blocker-kids.

Адміністративні меню й звіти перекладено українською. Після входу з чинним
паролем власника відкриваються статистика deutschmit.de, Quiz Arena та Shorts
Blocker Kids. Наскрізна перевірка підтвердила доступ до бота без другого входу;
наявні налаштування другого фактора та паролі не змінювалися.

Для Shorts Blocker Kids додано події переглядів, кліків і активного часу,
окрему таблицю, зведення сторінок/дій/джерел, список відвідувань із пагінацією
та послідовність дій вибраного відвідування. Producer додано до наявного
assets/site.js. Хеші index.html та assets/styles.css до/після однакові.

Перевірки:

- GitHub CI run 34853797926 успішний для runtime commit.
- Локальний `npm run ci` успішний; додаткові 8 тестів нового контракту й API успішні.
- Браузерний контроль: 2 перегляди + 2 фізичні кліки; той самий результат
  підтверджено збереженими подіями в робочій адмінці.
- PostgreSQL: повторна доставка не подвоює події, дані продуктів ізольовані,
  тестові записи виключаються, деталі відвідування повертають очікувані події.
- Шість звітів deutschmit та статистика бота повертають 200 після одного входу.
- Останній контрольний візит a0744499-df21-4c54-bcb7-5162a0b6ab05 позначений
  тестовим і виключений. Артефакт: .verification/admin-live-acceptance.json.

Історія кліків Shorts Blocker Kids до встановлення producer відсутня.
Блокувальники, відключений JavaScript, DNT/GPC та збої доставки можуть зменшувати
кількість подій. Відвідувач означає випадкову позначку браузера, не встановлену
особу. Deutsch Trainer залишається окремим непідключеним продуктом.
