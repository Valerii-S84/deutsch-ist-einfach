# Точка входу

Виконай погоджену задачу до перевіреного результату з мінімально достатніми витратами.
Цей файл керує навігацією та пріоритетами; кожна політика визначена у своєму документі.

## Пріоритет і межі

- Системні та розробницькі інструкції середовища мають вищий пріоритет за цей набір.
- Прямий запит користувача й надані раніше дозволи визначають поточну задачу в цих межах.
- Набір не змінює механізм завантаження та пріоритету вкладених правил конкретного агента.
- `core/` задає базові правила. `project/` заповнює параметри й може посилювати захист,
  але не дозволяє вигадувати докази, розкривати секрети чи обходити дозволи середовища.
- Мова, стиль, команди, Git-процес і числові бюджети налаштовуються в `project/`.
- За невирішеного конфлікту зупини тільки залежну дію, назви конкретні джерела
  та потрібне рішення. Продовжуй незалежну дозволену частину задачі.

## Шаблон і налаштований проєкт

`project/` у цьому репозиторії є шаблоном, а не описом вигаданого продукту.
Його незаповнені поля не блокують супровід набору, читання чи початкове налаштування.
Для роботи в цільовому репо встанови `profile: project` та заповни потрібні поля доказами.
Відсутня команда тестів не блокує пояснення документа, але блокує твердження про успіх цих тестів.
Не починай дію, для якої невідомі середовище, дозволи або необхідні захисні умови.

Нову задачу не доповнюй повним аудитом набору. Каталог `maintenance/` не є стартовим контекстом.

## Критичні вимоги адміністративного контролю

Адміністративна статистика та збереження контролю власника над продуктами — критичні вимоги. Рефакторинг, відокремлення або перейменування не дозволяють видаляти адміністративні можливості, метрики чи доступ до них без прямого дозволу власника. Перенесення функції завершене лише після перевірки її доступності та правильності в новому місці. Подальші зміни повинні зберігати й перевіряти статистику всіх підключених продуктів.

Карта продуктів, аудит втрат, контракт інтеграції та критерії приймання: [адміністративний контроль](../docs/admin-restoration.md). Для змін адмінки й статистики прочитай також [контракти метрик](../docs/statistics-contract.md).
