# Коротка перевірка перед завершенням

Це допоміжна пам'ятка до [критеріїв завершення](DEFINITION_OF_DONE.md), не окрема політика.
Не перечитуй її на кожній задачі та не запускай команди лише для заповнення пунктів.

- Чи отримано саме погоджений результат без побічних змін?
- Чи наявні докази всіх обов'язкових критеріїв?
- Чи правильно відокремлено невідоме й незавершене?
- Чи статус і короткий звіт відповідають доказам?
