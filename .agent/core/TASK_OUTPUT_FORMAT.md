# Формат результату

Для простої відповіді використовуй короткий абзац без порожніх розділів.
Для суттєвої виконаної задачі вкажи:

- статус за [критеріями](DEFINITION_OF_DONE.md) та отриманий результат;
- створені й оновлені файли або компактно визначену групу;
- фактично виконані перевірки та їх результат;
- незавершене, блокери й суттєві ризики, якщо вони є;
- commit або інші зовнішні дії, якщо вони входили до задачі.

Пиши мовою запиту або погодженою мовою проєкту. У самому наборі документація українською.
Масштаб пояснення відповідає запиту: замовлений докладний аналіз не обмежуй формою звіту про правку.
Не додавай непроханих покращень. Не заявляй чисте дерево, успішні тести або виміряну
економію без відповідного доказу. Звіт входить до завершення роботи.
