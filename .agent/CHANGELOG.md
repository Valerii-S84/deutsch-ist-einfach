# Історія змін

## 2.1.0 — 2026-09-06

- Додано п'ять необов'язкових профілів ролей, що не розширюють повноваження.
- Визначено самоперевірку, окреме рев'ю, передачу доказів і поведінку при недоступному рев'юері.
- Додано необов'язкові налаштування ролей та рев'ю з типовими значеннями для старих профілів 2.0.
- Розширено валідатор і сценарії; нові ролі не запускають допоміжних агентів автоматично.

## 2.0.0 — 2026-09-06

- Скорочено точку входу; документи підключаються за потребою.
- Додано бюджет із контролем безрезультатних повторів і чесним обліком без вигаданого ліміту.
- Узгоджено автономність, безпеку, завершення та статуси `Done`, `Partial`, `Blocked`.
- Прибрано універсальні вимоги до конкретного стеку, розміру коду та формату commit.
- Змінено формат `project/`: потрібне перенесення заповнених контекстів зі старої версії.
- Додано адаптер Codex, офіційні джерела для Astra, валідатор та сценарії перевірки.
- README та історію змін перекладено українською; другий README став посиланням.

## 1.0.0 — 2026-04-05

- Запроваджено `.agent/` з універсальним ядром і налаштуваннями проєкту.
- Перенесено правила меж задачі, завершення, звіту й чекліст у `core/`.
- Додано матрицю безпеки, Git-процес та інструкцію початкового налаштування.
- Розділено інженерні принципи й мовні налаштування стилю.
